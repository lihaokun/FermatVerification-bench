Use of these test files in this bench:
  GoblintCil's test/small1/ + test/small2/ historically exposed CIL parser
  corner cases (GCC extensions, alignment, designated initializers, _Alignas,
  _Generic, bitfields, VLA, etc.). These files have NO ACSL; they are pure C
  frontend stress tests. Bench Part 1 (C language features) uses them to test
  any frontend's coverage by exposing it to these constructs.

  Expected outcomes will vary across consumers (e.g., frama-c may reject some
  GCC-specific extensions that goblintcil accepts; recording this divergence
  is the point of differential testing).
