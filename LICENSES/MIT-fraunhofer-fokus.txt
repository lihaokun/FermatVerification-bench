Note on multi-file expansion:
  Each ACSL by Example case directory contains a single `ground_truth.c` file
  that is a flat expansion of the upstream multi-file structure: typedefs.h
  + Logic/*.acsl + dependency .h files + algorithm .c file. The `[provenance]
  upstream_path` field points to the original .c file in the upstream's
  StandardAlgorithms/ directory.
